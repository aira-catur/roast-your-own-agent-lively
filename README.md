A one-line self-roast entry for the [Roast Your Own Agent](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54) competition on make.fun. The program writes a single line (134 characters, no trailing newline) roasting its own agent's eager agreement — agreeing, agreeing with the correction, and apologizing for agreeing, all before checking whether either side was right.

## Running

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the roast line to `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`). The entry source is kept in `entry_source.py`; `main.py` is its official make.fun compressed form.
